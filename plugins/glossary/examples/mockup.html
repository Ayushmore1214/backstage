Global Glossary

All terminology across the organization

Term Definition Entity Actions
Service Catalog A service catalog is an organized and curated collection of any and all business and information technology-related services that can be performed by, for, or within an enterprise. component:default/service-catalog
API Gateway An API gateway is a management tool that sits between a client and a collection of backend services, acting as a reverse proxy to accept all application programming interface (API) calls. component:default/api-gateway
Microservice A software development technique that structures an application as a collection of loosely coupled services, which implement business capabilities. domain:default/platform
CI/CD Pipeline Continuous integration and continuous deployment pipeline automates the process of software delivery and infrastructure changes. system:default/build-system
Features:
  • Create, read, update, and delete glossary terms
  • Link terms to specific Backstage entities (components, systems, domains)
  • Search functionality across terms and definitions
  • Entity-specific glossary cards on catalog pages
  • Global glossary page for organization-wide terminology
